Icon Studio: A Skill That Builds Icon Libraries

Getting AI to produce consistent design output is a systems problem, not a prompting problem. I built the skill that encodes that system, then used it to make three icon sets in three very different styles.

Hero: the three sets side by side on one strip
Role
Solo
Timeline

Tools
Claude, Node + resvg, Figma, GitHub Pages
Output
55 icons, 3 sets

TL;DR

I built icon-studio, a Claude skill that turns a style (rules or reference images) and an icon list into a consistent, production-ready icon set: hand-written SVGs, checked by script against a locked rules file, previewed on a fixed house-style page and exported as SVG + PNG. I then used it to make three sets in three very different styles.

The problem

A nice first icon, then a drifting set.

Asking an AI for “icons in this style” gets you a nice first icon and a drifting set. Each icon invents its own stroke, detail level, colours and size, so the family stops looking like one person drew it.

What I wanted instead

01

Consistency by construction

Every number (grid, stroke, palette, shape budget) lives in one file, and no icon gets an exception.

02

Verifiable output

Checks a script can run, not just “looks fine to me”.

03

Reusable across styles

The same process should work for a flat folk set and a sketchy line set.

04

Designer-ready delivery

Real SVGs I can copy into Figma, PNGs, and a page to review them on.

Building the skill

The rules are the product.

A set stays consistent because every decision is written down once and checked mechanically.

icon-studio workflow: two review gates

Gate A checks the four anchors against the references before anything else is drawn; Gate B repeats the checks for every batch.

Three sets, three styles

Each set stress-tested a different part of the system.

The rule version history is the clearest record of what I caught and fixed.

Set 1 · 28 icons

Restaurant Folk Icons

Flat two-tone folk

Brief: Indian-folk menu icons (burgers, chai, biryani handi, utensils), palette sampled from a pink/red/orange cocktail-menu reference.

What changed

  • v1 → v2

    The first pass came out as spot illustration (19–31 shapes per icon, sparkles, shadows, tilt). I cut it to 12 shapes, two tones per part and no decoration, so it reads as icons.

  • v2.1

    Added translucent layering from the reference, capped at 3 overlaps and only on six named icons.

  • v2.2

    Every shade must start and end on the object's own edge or seam. Driven by a croissant that took three redraws before it read as five segments rather than overlapping blobs. This became a rule in the skill itself.

  • Bug

    The page script stripped width/height from inner rects, so the burger patty and cocktail stem vanished on the page and in copied SVG. Fixed in the skill's build script.

Set 2 · 10 icons

Travel Ink

Hand-drawn line

Brief: luggage and documents in the style of a bike illustration: dark grey ink with pop accents.

What changed

  • v1.1

    I spotted the passport was the only filled icon. It traced back to a one-off rule exception, so I removed the exception rather than patching the icon.

  • v2.0

    Added a hand-drawn line. Icons are drawn clean on the grid, then a script generates the sketched version, so the wobble is consistent and the source stays editable.

  • v2.1

    Dropped yellow; every icon must use both green and tangerine.

  • Flagged

    The striped duffel read as a basket; the boarding pass and ID card shared a silhouette.

How I directed the AI

Four habits made it a system, not a one-off.

  1. Fix the rule, not the icon.

    When something looked wrong, I asked whether it was a one-off or a gap in the rules. The passport exception and the croissant both became rule changes that apply to every future set.

  2. Review rendered output, not code.

    I judged contact sheets, silhouettes and the live page. That is how I caught the missing burger patty, which no lint check would have found.

  3. Write taste down as constraints.

    “Fewest parts when unsure”, “no beige”, “group by category, never by batch” are subjective calls turned into checkable rules.

  4. Feed lessons back into the tool.

    Each set improved the skill: the layering rule, the fixed preview page, the rect bug fix and the “Copy all” for Figma all came from using it.

Outcome

55 icons across three styles, from one skill.

Per set, only the rules file and page config changed, plus one set-specific script (the sketch generator for Travel). Each set ships as SVG, PNG at three sizes, contact sheets, the rules files and a preview page.
